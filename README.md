# ☕ Fjäll & Fika – Coffee Shop Website

**Fjäll & Fika** is a responsive coffee shop website inspired by Swedish mountain culture and the tradition of *fika*.  
The project showcases a warm, nature-inspired design combined with clean front-end structure and usability.

This project was built as a **front-end portfolio project** using **HTML, CSS, and JavaScript**.

---

## 🌄 Project Overview

The website includes:
- A landing page with a hero section and featured products
- Menu sections for coffee, waffles, pizza, and hot drinks
- Multi-page navigation
- A responsive header with a mobile hamburger menu
- A structured footer with contact details and social links

The design focuses on clarity, accessibility, and responsiveness across devices.

---

## 🛠️ Tech Stack

- **HTML5** – semantic and accessible markup  
- **CSS3** – responsive layout, typography, and styling  
- **JavaScript (Vanilla)** – mobile navigation toggle  
- **Google Fonts** – Playfair Display & Inter  
- **Font Awesome** – icons  

---

## ✨ Features

- Fully responsive design (mobile, tablet, desktop)
- Clean and modern UI inspired by Scandinavian cafés
- Card-based layout for product presentation
- Call-to-action buttons linking to the menu page
- Accessible HTML (alt text, semantic elements, aria labels)
- Lightweight and fast-loading (no frameworks)

---

## 🎯 Purpose of the Project

This project was created to:
- Practice modern front-end development fundamentals
- Demonstrate layout, responsiveness, and UI design skills
- Serve as a portfolio project for internships and junior front-end roles
